Module 2

Markov Chains I: The Basics

Know cold

  • Markov property. \( P(X_{n+1}=j \mid X_n=i, X_{n-1},\dots,X_0) = P(X_{n+1}=j \mid X_n=i) = p_{ij} \). Time homogeneity is the default assumption. Rows of \(P\) are "from" and sum to 1, and time starts at 0. "Where you go next depends at most on where you are now," so an i.i.d. sequence is also a Markov chain.
  • Notation. The lecture writes \(p^{(n)}_{ij}\) for the n-step probability. The parentheses mean it's an entry of \(P^n\), not \(p_{ij}\) raised to a power. \(p^{(0)}_{ij}=\delta_{ij}\) (1 if \(i=j\), else 0).
  • Path probability. \( P(X_0=i_0, X_1=i_1,\dots,X_n=i_n) = \alpha_{i_0}\,p_{i_0 i_1} p_{i_1 i_2}\cdots p_{i_{n-1} i_n} \), where \(\alpha\) is the initial distribution. An unconditional probability like \(P(X_1=W)\) needs \(\alpha\). Conditioning on \(X_0\) makes it cancel.
  • A specific path vs. a skipped step. When every intermediate state is named (S→F→S), multiply one-step entries. Use \(P^2\) only when the intermediate state is unspecified, because \(p^{(2)}_{ij}\) sums over all of them.
  • n-step / Chapman–Kolmogorov. \( p^{(n)}_{ij} = \sum_k p^{(m)}_{ik}\,p^{(n-m)}_{kj} \) for any \(0\le m\le n\), so \(P^{(n)}=P^n\). Matrix powers commute: \(P^{(m)}P^{(n)}=P^{(n)}P^{(m)}\). Distribution at time \(n\): row vector \( \alpha P^n \).
  • Missing time steps. \( P(X_5 = j \mid X_2 = i) = p^{(3)}_{ij} \). In the conditioning, only the most recent given value matters: \(P(X_4=2\mid X_2=5, X_0=0) = P(X_4=2\mid X_2=5) = p^{(2)}_{52}\). Conditioning on a later time needs Bayes: \( P(X_1=i\mid X_3=j) = \dfrac{P(X_1=i)\,p^{(2)}_{ij}}{P(X_3=j)} \).
  • Conditional independence. Given the present, past and future are independent. That does not make \(X_{n-1}\) and \(X_{n+1}\) independent unconditionally.
  • Conditional probability toolkit. \( P(A\mid B)=P(A\cap B)/P(B) \), law of total probability \( P(A)=\sum_k P(A\mid B_k)P(B_k) \), and the chain rule \( P(A\cap B\cap C) = P(A)P(B\mid A)P(C\mid A\cap B) \). Total probability also works inside a conditional universe: \( P(X=x\mid Y=y)=\sum_z P(X=x\mid Y=y,Z=z)\,P(Z=z\mid Y=y) \). The instructor's hint "condition on Y" means this.
  • Building P from a story. Fill in every entry one by one at least once. Using "rows sum to 1" to fill gaps copies any earlier mistake forward. Lecture example: 2 green and 4 white balls, 3 per bucket, one ball swapped each step, \(X_n\) = greens in bucket 1. Then \(p_{01}=\tfrac23\) (draw a green from bucket 2), \(p_{11}=\tfrac13\cdot\tfrac13+\tfrac23\cdot\tfrac23=\tfrac59\), and \(p_{02}=p_{20}=0\).

The lecture's main tool: make the forbidden state absorbing

For "never visits state C" questions, build a new matrix \(Q\). It's \(P\) with row C replaced by "stay in C with probability 1". The original chain and the modified chain move identically until C is hit, so "C was never visited by time \(n\)" is the same event as "the \(Q\)-chain isn't in C at time \(n\)".

\[ \begin{aligned} P(X_1,\dots,X_n\ne C\mid X_0=S) &= 1-q^{(n)}_{SC} \\ P(X_4=S\mid X_1,X_2,X_3\ne C,\ X_0=S) &= \frac{q^{(4)}_{SS}}{1-q^{(3)}_{SC}} \\ P(X_4=S\mid X_1,\dots,X_4\ne C,\ X_0=S) &= \frac{q^{(4)}_{SS}}{1-q^{(4)}_{SC}} \end{aligned}\]
  1. Copy \(P\), then set row C to all zeros except a 1 in column C.
  2. Raise \(Q\) to the needed powers. In the notebook that's one matrix_power(Q, n) call.
  3. Write the target as a joint probability over a conditioning probability, and read both off \(Q^n\). Avoid brute force: the instructor enumerates 27 paths only to show why this trick exists.
  4. Sanity check: extra "not C" information should move the answer in the direction that makes sense (here it raises P(sunny)).

Bonus, not in the lectures: the canonical form

Useful for checking absorption answers, but the lectures never teach it. Note that its \(Q\) (transient-to-transient block) means something different from the lecture's \(Q\) above. With transient states first, \( P = \begin{pmatrix} Q_T & R \\ 0 & I \end{pmatrix} \) and \( N = (I - Q_T)^{-1} \). Then \(N_{ij}\) = expected visits to transient \(j\) from \(i\), expected steps to absorption are \( t = N\mathbf{1} \), and absorption probabilities are \( B = NR \). On the exam you can always get the same answers by first-step analysis (Module 4).

A longer history in a Markov framework

If \(X_{n+1}\) depends on both \(X_n\) and \(X_{n-1}\), define the pair \(Y_n = (X_{n-1}, X_n)\). Then \(Y\) is a Markov chain with \(k^2\) states. A transition \((a,b)\to(c,d)\) is only possible when \(c=b\). The probability of a specific pair path like SF→FS→SZ is the product of the one-step entries along it.

Traps
  • \(\alpha P^n\) uses a row vector on the left. Writing \(P^n\alpha\) gives a wrong answer that still looks plausible.
  • \(p^{(n)}_{ij} \ne (p_{ij})^n\). Raise the matrix to the power, not the single entry. The instructor's example: \(p^{(2)}_{AD}\ne(p_{AD})^2\).
  • "\(X_3\ne C\)" is not a specific state, so you can't use the Markov property to drop the earlier conditions. Use the absorbing trick.
  • Don't fall back to the last specific known value, as in \(P(X_4=S\mid X_0=S)\). The "not C" information still matters (P2.4 shows the gap).
  • Never write two conditioning bars. Combine conditions with a comma: \(P(A\mid B, C)\).

Module 3

Markov Chains II: Limiting Distributions

Know cold

  • Communication. \(i\to j\) if \((P^n)_{ij}>0\) for some \(n\ge0\). \(i\leftrightarrow j\) is an equivalence relation, and its classes are the communication classes. The chain is irreducible if there's one class.
  • Hitting vs return time. First hitting time \(T_i=\min\{n\ge0: X_n=i\}\). First return time \(\min\{n\ge1: X_n=i\}\) given \(X_0=i\). Shorthand: \(P_i(\cdot)\) and \(E_i[\cdot]\) mean "given \(X_0=i\)".
  • Recurrent vs transient. The lecture writes \(g_i = P(\text{ever return to } i\mid X_0=i)\) (some texts use \(f_{ii}\)). The state is recurrent if \(g_i=1\) and transient if \(g_i\lt 1\).
  • Computing \(g_i\): split on the first return. \(g_i=\sum_{n\ge1}P(\text{first return at step } n)\). Lecture example: \(g_1 = p_{11} + p_{13}\sum_{n\ge0}p_{33}^{\,n}\,p_{31}\). The word "first" matters: "back at \(i\) at step \(n\)" events overlap, and \(\sum_n p^{(n)}_{ii}\) isn't a probability.
  • Positive vs null recurrent. A recurrent state is positive recurrent if \(E_i[\text{return time}]\lt\infty\) and null recurrent if it's \(\infty\). Both are class properties. The symmetric random walk is recurrent but null.
  • Sum test. \(N=\sum_{n\ge1}\mathbb 1\{X_n=i\}\) counts returns, and \(E[\mathbb 1_A]=P(A)\) gives \(E_i[N]=\sum_{n\ge1} p^{(n)}_{ii}\). So \(i\) is recurrent ⇔ \( \sum_{n\ge1} p^{(n)}_{ii} = \infty \).
  • Returns to a transient state. \(N\mid X_0=i\sim\text{Geom}_0(1-g_i)\): \(P_i(N=j)=g_i^{\,j}(1-g_i)\), \(P_i(N\ge k)=g_i^{\,k}\), \( E_i[N] = \dfrac{g_i}{1-g_i} \). The course's \(\text{Geom}_0(p)\) has \(P(X=x)=(1-p)^xp\) for \(x=0,1,\dots\) and mean \((1-p)/p\). \(\text{Geom}_1\) starts at 1. Counting the visit at time 0 too gives \(1/(1-g_i)\).
  • Class properties. Recurrence, transience and period are shared by every state in a class. In an irreducible chain, check just one convenient state.
  • Finite chains. At least one state is recurrent. An irreducible chain on a finite state space is automatically positive recurrent. A class you can leave and never come back to is transient. The easiest proof of transience is an escape path with no way back.
  • Communication edge cases. \(i\to i\) always (take \(n=0\)). One-way movement between classes is possible. Two-way movement would merge them into one class.
  • Period. \( d(i) = \gcd\{n\ge1 : (P^n)_{ii}>0\} \). The state is aperiodic if \(d=1\). A self-loop (\(P_{ii}>0\)) makes the whole class aperiodic.
  • Simple random walk on \(\mathbb Z\). \( (P^{2n})_{00} = \binom{2n}{n}p^nq^n \approx \dfrac{(4pq)^n}{\sqrt{\pi n}} \). It's recurrent iff \(p=\tfrac12\), and then it's null recurrent. Symmetric walks are recurrent in 1D and 2D and transient in 3D and up.

Existence and uniqueness of the limiting distribution

For an irreducible, recurrent, aperiodic chain, the lecture's theorem says that for every starting state \(i\):

\[ \lim_{n\to\infty} p^{(n)}_{ij} = \frac{1}{E_j[\text{return time to } j]} \]

If \(j\) is null recurrent, the expected return time is \(\infty\), so the limit is 0 and there's no limiting distribution. If it's positive recurrent (ergodic = irreducible + positive recurrent + aperiodic), the limits form the distribution \(\pi\) with \(\pi P=\pi\), \(\sum_j\pi_j=1\).

Quiz workflow for a finite chain: (1) check it's irreducible, (2) find a state with a self-loop to show it's aperiodic, (3) finite + irreducible gives positive recurrence for free. Then the limit exists, doesn't depend on the start, and equals the solution of \(\pi P=\pi\).

Drop aperiodicity and a stationary distribution can still exist without \(P^n\) converging, e.g. \( \begin{pmatrix}0&1\\1&0\end{pmatrix} \). Drop irreducibility and the limit can depend on where you start. Lecture example: a block-diagonal 4-state chain whose limit is \((3/5,2/5,0,0)\) or \((0,0,3/7,4/7)\) depending on which block you start in. Solve each closed block separately.

Total variation distance

\[ \lVert \mu-\nu\rVert_{TV} = \max_{A}\,|\mu(A)-\nu(A)| = \tfrac12 \sum_i |\mu_i-\nu_i| \]

The lecture calls ½ Σ the true definition. It says you can drop the ½ when you only care about convergence, but use the ½ for numeric answers. The distributions can have different supports: \((\tfrac13,\tfrac13,\tfrac13)\) vs \((\tfrac12,\tfrac12,0)\) gives \(\tfrac12(\tfrac16+\tfrac16+\tfrac13)=\tfrac13\).

Random walk details

\(p^{(n)}_{00}=0\) for odd \(n\), so the period is 2. The lecture uses Stirling's formula \(n!\sim\sqrt{2\pi}\,n^{n+1/2}e^{-n}\) together with the limit comparison test on \(\sum p^{(2n)}_{00}\). Intuition: when \(p\ne\tfrac12\) the walk drifts away and is transient.

Traps
  • "Closed" and "recurrent" coincide only for finite chains. A symmetric random walk on \(\mathbb Z\) is irreducible but null recurrent, so it has no stationary distribution.
  • One self-loop anywhere in an irreducible chain makes every state aperiodic.
  • Finding the period requires the gcd of all return times. A shortest return that isn't 1 doesn't rule out period 1: returns in 3 and 7 give gcd 1.
  • Recurrent doesn't mean finite expected return time. The symmetric random walk returns with probability 1, but the expected wait is infinite.
  • When splitting a return probability over \(n\), say "first return at step \(n\)". Otherwise the events overlap and you double count.

Module 4

Markov Chains III: Stationary Distributions & First-Step Analyses

Know cold

  • Stationary, by hand (lecture method). Write each \(\pi_j\) equation by reading down column \(j\) of \(P\): \(\pi_j=\sum_i\pi_i p_{ij}\). Drop any one equation, add \(\sum\pi_j=1\), and solve \(A\vec\pi=(0,\dots,0,1)^T\). Decimals are fine.
  • Every limiting distribution is stationary (proved in lecture). The converse fails: a stationary distribution can exist with no limit (periodic), and it can be non-unique. With \(P=I\) on {0, 1}, both \((1,0)\) and \((0,1)\) are stationary.
  • Irreducible and positive recurrent ⇒ there's a unique stationary \(\pi\), and \( \pi_j = 1/m_j \), where \(m_j\) is the mean return time to \(j\). Aperiodicity is needed only for the limit, not for uniqueness.
  • Started from \(\pi\), the chain stays stationary at fixed times (\(X_n\sim\pi\) for every fixed \(n\)), but not at random times like a hitting time.
  • Long-run proportion of time in \(j\) is \(\pi_j\). The lecture treats this as a limiting-distribution question for an ergodic chain.
  • Two-state shortcut. \( P=\begin{pmatrix}1-a&a\\b&1-b\end{pmatrix} \Rightarrow \pi = \left(\dfrac{b}{a+b}, \dfrac{a}{a+b}\right) \), and the second eigenvalue is \(\lambda_2 = 1-a-b\).
  • Detailed balance \(\pi_ip_{ij}=\pi_jp_{ji}\) for all \(i,j\) ⇒ \(\pi\) is stationary. It's a quick way to solve birth–death chains.
  • Eigenvalues. \(\vec\pi=\vec\pi P\) makes \(\pi\) a left eigenvector for eigenvalue 1. Every eigenvalue of a stochastic matrix has \(|\lambda|\le1\) (Perron–Frobenius). Order them \(1=\lambda_1\gt|\lambda_2|\ge|\lambda_3|\ge\cdots\). They can be negative.
  • Convergence rate (lecture form, in total variation). \( \lVert p^{(n)}_{i\cdot}-\pi\rVert_{TV} \le C\,|\lambda_2|^n \), where \(C\) depends on the start \(i\). Convergence is geometric. The closer \(|\lambda_2|\) is to 1, the slower the mixing. The lecture gives no recipe for an exact number of steps, and the instructor says this video won't affect a perfect score.
  • Tail-sum identity. For a nonnegative integer random variable, \( E[X]=\sum_{x\ge0}P(X\gt x) \). The instructor calls it "an important tool" on its own.

First-step analysis: one recipe for four question types

  1. Name the unknown for every state: \(h_i\), \(u_i\) or \(v_i\).
  2. Condition on the first move: unknown at \(i\) = (cost of one step) + Σ\(_k P_{ik}\) · unknown at \(k\).
  3. Set the boundary values, then solve the linear system.
\[ \begin{aligned} \text{Expected hitting time of } A: &\quad u_i = 1 + \textstyle\sum_k p_{ik} u_k,\;\; u_A = 0 \\ \text{Mean return time to } j: &\quad m_j = 1 + \textstyle\sum_k p_{jk} u_k \;(\text{with } u_j=0) \\ \text{P(hit } A \text{ before } B): &\quad p_i = \textstyle\sum_k p_{ik}\, p_k,\;\; p_A=1,\; p_B=0 \\ \text{Expected visits to } j \text{ before hitting target } t: &\quad W_{ij} = \mathbb 1[i=j] + \textstyle\sum_k p_{ik} W_{kj},\;\; W_{tj}=0 \end{aligned}\]

When to write "1 +". Expected-time equations always start with "1 +". Probability equations never do. Visit-count equations get the "1" only in the row where the start state is the state being counted (the start counts as a visit).

Visits and hitting time are linked. The lecture's stopping state is an ordinary state, not necessarily an absorbing one. The expected hitting time of the target equals the sum of expected visits to every non-target state: \(u_i=\sum_{j\ne t}W_{ij}\). Expected visit counts don't have to be integers (the lecture gets 1.2844).

Mean pattern times (lecture methods)

Method 1: non-overlapping patterns (no proper prefix equals a suffix, e.g. HTT, MARKOVCHAIN). For i.i.d. symbols and a pattern of length \(L\), the pattern can only finish at time \(n+L\) if it hasn't appeared by time \(n\), so \(P(T=n+L)=P(\text{pattern})\,P(T\gt n)\). Sum over \(n\ge0\) and use the tail-sum identity:

\[ 1 = P(\text{pattern})\,E[T] \quad\Longrightarrow\quad E[T]=\frac{1}{P(\text{pattern})} \]

Fair coin, HTT: \(E[T]=8\). A monkey typing MARKOVCHAIN on 26 keys: \(26^{11}\).

This fails for patterns that overlap themselves (HH, HTH, HHH). The lecture's example of failure is HHH. For those, use first-step analysis. The instructor says martingale methods are "outside of the scope of this course." Check values: \(E[T_{HH}]=6\), \(E[T_{HTH}]=10\), \(E[T_{HHH}]=14\).

Method 2: the lecture's sliding-window chain. Let \(Y_1,Y_2,\dots\) be the flips and \(X_n=(Y_n,Y_{n+1},Y_{n+2})\). That's 8 equally likely states, so \(P(X_1=i)=\tfrac18\). Let \(T=\min\{n\ge1: X_n=\text{HTT}\}\) and \(u_i=E[T\mid X_1=i]\). Here hitting is counted from \(n\ge1\), so \(u_{HTT}=1\), not 0. Solve the first-step system, then:

\[ E[T]=\tfrac18\textstyle\sum_i u_i = 6, \qquad E[\#\text{flips}] = E[T]+2 = 8 \]

The "+2" is there because the window that completes the pattern at index \(T\) ends at flip \(T+2\).

Traps
  • Mean return time: in the \(u_1\) equation, the 1→1 term is "\(+\,p_{11}\cdot 0\)". The instructor repeats this: do not write \(u_1\) there.
  • Hit-before probabilities from different starting states don't need to add up to 1. Each one lives in a different conditional universe.
  • "Stationary" and "limiting" are different claims. Periodic chains have the first without the second.
  • Don't apply \(E[T]=1/P(\text{pattern})\) to an overlapping pattern. Check prefix vs. suffix first.
  • In the sliding-window pattern chain, the target's value is 1, and you add 2 at the end. Copying the general rule "\(u_A=0\)" there gives the wrong answer.

Module 5

Simulation & Markov Chain Monte Carlo

Direct simulation from \(U\sim\text{Unif}(0,1)\)

  • Discrete ("interval chopping"). Set \(X=x_k\) when \(F(x_{k-1}) \lt U \le F(x_k)\). A Markov chain step from state \(i\) chops \([0,1]\) using row \(i\) of \(P\), so you simulate a sample path one row at a time. With infinite support (e.g. geometric), build each interval endpoint only when you need it.
  • Inverse CDF. \(X=F^{-1}(U)\). Why it works: \(P(F^{-1}(U)\le y)=P(U\le F(y))=F(y)\), because \(F\) is non-decreasing. Exponential(rate λ): the lecture derives \(F^{-1}(u)=-\tfrac1\lambda\ln(1-u)\). Using \(-\ln(U)/\lambda\) gives the same distribution, but \(-\ln(1-u)/\lambda\) is the actual inverse. For \(f(x)=2x\) on [0, 1]: \(X=\sqrt U\).
  • Checking a sampler. Plot a histogram of many draws against the target density. The y-axis must be a density: bin proportion ÷ bin width.

Accept–reject, with the lecture's letters

Target density \(f\). Pick an envelope \(g\) with \(g(x)\ge f(x)\) everywhere. Let \(c=\int g\), and the proposal density is \(h=g/c\). (Some books call the proposal \(g\). In this course \(g\) is the envelope and \(h\) is the proposal.)

  1. Draw \(Y\sim h\) and \(U\sim\text{Unif}(0,1)\).
  2. Accept \(Y\) if \( U \le \dfrac{f(Y)}{g(Y)} = \dfrac{f(Y)}{c\,h(Y)} \). Otherwise try again.
  3. P(accept) = \(1/c\). The number of tries \(N\) is Geometric starting at 1, with \(E[N]=c\).
  4. Smallest valid \(c\): \(c=\max_x f(x)/h(x)\). A bigger \(c\) means a lower acceptance rate and a longer wait.
  5. \(h\) needs heavier tails than \(f\), or \(f/h\) is unbounded and no \(c\) works.

Lecture example: \(f(x)=\tfrac{27}{2}x^2e^{-3x}\) on \(x\gt0\). \(h=\)Exp(3) fails because \(f/h=\tfrac92x^2\) is unbounded. \(h=\)Exp(2) works: \(f/h=\tfrac{27}{4}x^2e^{-x}\) peaks at \(x=2\), so \(c=27e^{-2}\approx3.65\) and P(accept) ≈ 0.274.

Markov chains on a continuous state space

The transition density \(p(x,y)\) is a PDF in \(y\) for each fixed \(x\): \(\int_S p(x,y)\,dy=1\). The stationary equation is the continuous version of \(\pi_j=\sum_i\pi_ip_{ij}\):

\[ \pi(y)=\int_S \pi(x)\,p(x,y)\,dx \]

Detailed balance ⇒ stationary. If \(\pi(x)p(x,y)=\pi(y)p(y,x)\), integrate both sides over \(x\): \(\int\pi(x)p(x,y)\,dx=\pi(y)\int p(y,x)\,dx=\pi(y)\). This is why every MCMC recipe works.

Metropolis–Hastings

Target \(\pi\), known up to a constant (it only appears in a ratio). Proposal density \(q(x,y)\) for moving from \(x\) to \(y\) (the same as \(q(y\mid x)\)). From current state \(x\), propose \(y\) and accept with probability:

\[ \alpha(x,y) = \min\!\left(1,\; \frac{\pi(y)\,q(y,x)}{\pi(x)\,q(x,y)}\right) \]

If you reject, stay at \(x\), and record \(x\) again. The chain always moves forward in time. In code you can skip the min and just compare \(U\) to the raw ratio.

Transition kernel and why it works. \(p(x,y)=q(x,y)\,\alpha(x,y)\) for \(y\ne x\), plus a point mass for staying put: \(p(x,\{x\})=\int_S q(x,y)\big(1-\alpha(x,y)\big)\,dy\). Moving \(\pi(x)q(x,y)\) inside the min shows \(\pi(x)p(x,y)=\min\big(\pi(x)q(x,y),\,\pi(y)q(y,x)\big)\), which is symmetric in \(x,y\). That's detailed balance. History: Metropolis used a symmetric \(q\), and Hastings generalized it to any \(q\).

Independence proposal (the one the lectures use in both examples). \(q(x,y)=q(y)\): propose without looking at \(x\). Then

\[ \alpha(x,y)=\min\!\left(1,\ \frac{\pi(y)\,q(x)}{\pi(x)\,q(y)}\right)=\min\!\left(1,\ \frac{\pi(y)/q(y)}{\pi(x)/q(x)}\right) \]
  • Example 1. \(\pi(x)\propto x(1-x)^2e^{-x^2/2}\) on [0, 1] with Unif(0, 1) proposals. Since \(q\equiv1\), the ratio is \(\pi(y)/\pi(x)\). That's because \(q\) is constant, not because it's symmetric.
  • Example 2. \(\pi(x_1,x_2)\propto x_1^2e^{-x_1(1+x_2)}\) on \(x_1,x_2\gt0\), with \(Y_1,Y_2\) i.i.d. Exp(1) proposals. Then \(q(y)=e^{-y_1-y_2}\) and \(\pi/q=x_1^2e^{-x_1x_2+x_2}\).
  • Random-walk proposal (\(y=x+\varepsilon\), symmetric): the ratio is \(\pi(y)/\pi(x)\). This is standard, but the lectures don't use it in their examples.

Getting draws. Discard a burn-in period. Then either restart independent chains, or keep every ~100th value (thinning). With random-walk proposals, a small step size means nearly everything is accepted but the chain crawls, and a big one means nearly everything is rejected.

Gelman–Rubin \(\hat R\) (from the ungraded lab, not a video)

Run \(m\) chains of length \(n\) (after burn-in). Let \(\bar\theta_j\) be the mean of chain \(j\), \(s_j^2\) its variance, and \(\bar\theta\) the grand mean.

\[ W = \frac1m\sum_j s_j^2,\quad B = \frac{n}{m-1}\sum_j(\bar\theta_j-\bar\theta)^2,\quad \hat V = \frac{n-1}{n}W + \frac1n B,\quad \hat R = \sqrt{\hat V / W} \]

\(\hat R \approx 1\) (common cutoff < 1.1) suggests the chains have mixed. A large \(\hat R\) means the chains still disagree, so keep running.

Gibbs sampler & perfect simulation

  • Gibbs (needs \(k\ge2\) coordinates). Each sweep updates the coordinates in order, always using the newest values: \(x_1^{(n+1)}\sim\pi(x_1\mid x_2^{(n)},x_3^{(n)})\), then \(x_2^{(n+1)}\sim\pi(x_2\mid x_1^{(n+1)},x_3^{(n)})\), and so on. The lecture proves it works by checking the stationary equation directly.
  • Finding a full conditional. Write the joint, keep only the factors that involve \(x_k\), and recognize the kernel (normal, gamma, beta…). Lecture example: \(\pi(x_1\mid x_2)=\tfrac12(1+x_2)^3x_1^2e^{-x_1(1+x_2)}\), which is Gamma(3, rate \(1+x_2\)).
  • Course gamma convention. \(\Gamma(\alpha,\beta)\) with \(\beta\) a rate: density \(\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}\), and \(\Gamma(n)=(n-1)!\). Also watch exponential rate vs. mean.
  • Speed. In the lecture, Gibbs converged in about 10 steps vs. about 500 for MH. That was because the MH proposal was naive, not a general rule.
  • Bivariate normal (extra, not from the videos). With correlation ρ, \(X\mid Y=y \sim N(\rho y,\ 1-\rho^2)\), and \(Y\mid X=x\) is symmetric. Mixing gets slow as \(|\rho|\to1\).

Perfect simulation: coupling from the past (Propp–Wilson)

  1. Draw one uniform \(U_{-1}\) and use it to move a copy of the chain from every state from time −1 to time 0. If all copies land in the same state, that state is an exact draw from \(\pi\).
  2. If not, go back one more step: draw \(U_{-2}\), run every state from −2 to −1, then append the old paths and reuse \(U_{-1}\) from −1 to 0.
  3. Keep going back one step at a time (−3, −4, …), always reusing the earlier uniforms, until every path coalesces by time 0. You only need to store the \(U\)'s. The coalescence time is random.

Why not run forward until the copies meet? Stationarity holds at fixed times, not at a random meeting time, so forward coupling is biased. For monotone chains you only need to run the top and bottom paths. Lecture example: a 3-state chain with \(\pi=(10/23,\,7/23,\,6/23)\).

Traps
  • On an MH rejection, the chain stays flat and the repeated value counts. Leaving it out of the sample biases the result.
  • With a non-symmetric proposal you must keep the \(q(y,x)/q(x,y)\) correction. An independence proposal is non-symmetric unless \(q\) is constant.
  • CFTP: going back one step and restarting with fresh uniforms, or running forward until the copies meet, are both wrong. The instructor calls reusing the old uniforms "really critical".
  • Accept–reject: \(f/h\) has to be bounded everywhere, including the tails. Accept on \(f/g\) with the envelope \(g\), or on \(f/(c\,h)\) with the proposal \(h\). Don't mix the two.
  • Parameterizations: exponential rate vs. mean, gamma rate vs. scale. The lectures also reuse the letter \(q\) for different one-dimensional densities.

Module 6

Reinforcement Learning & Markov Decision Processes

Know cold

  • Ingredients (lecture notation). States \(s\), actions \(a\), dynamics \(p(s',r\mid s,a)\) and transitions \(p(s'\mid s,a)\). A prime means "next time step". Discount \(\gamma\) is between 0 and 1 inclusive. Policy \(\pi(a\mid s)\). The MDP assumes the Markov property and stationarity (time homogeneity). \(E_\pi\) means "computed under policy \(\pi\)", not a starting distribution as in Modules 2–4.
  • Rewards: the course uses only two forms. \(r(s,a)=E[R_t\mid S_{t-1}=s,A_{t-1}=a]\) and \(r(s)=E[R_t\mid S_{t-1}=s]=\sum_a\pi(a\mid s)\,r(s,a)\). (No \(r(s,a,s')\).) Setting the rewards well "is crucial" to steering the agent.
  • Return. Continuing tasks: \(G_t = \sum_{k\ge0}\gamma^k R_{t+k+1}\), with the key identity \(G_t=R_{t+1}+\gamma G_{t+1}\). Episodic tasks: \(G_t=R_{t+1}+\dots+R_T\), where \(T\) is random. To make an episodic task continuing, add an imaginary absorbing state with reward 0. Don't make the goal itself absorbing, or its reward gets collected forever.
  • Values. State value \(v_\pi(s)=E_\pi[G_t\mid S_t=s]\), which is "central to everything" in this module. Action value \(q_\pi(s,a)=E_\pi[G_t\mid S_t=s,A_t=a]\).
  • Effect of \(\gamma\). \(\gamma=0\) is short-sighted (next reward only). \(\gamma=1\) is allowed but can diverge. 0.9–0.95 is typical. Raising \(\gamma\) from 0.9 to 0.99 flipped some arrows toward the truly shorter path but slowed the iteration. Tune it by experimenting and comparing policies.
\[ \begin{aligned} \text{Bellman, } q \text{ form:}\quad & q_\pi(s,a) = r(s,a) + \gamma\sum_{s'} p(s'\mid s,a)\,v_\pi(s') \\ \text{Link:}\quad & v_\pi(s) = \sum_a \pi(a\mid s)\,q_\pi(s,a) \\ \text{Bellman, } v \text{ form:}\quad & v_\pi(s) = r(s) + \gamma\sum_{s'} p(s'\mid s)\,v_\pi(s'),\qquad p(s'\mid s)=\sum_a p(s'\mid s,a)\,\pi(a\mid s) \\ \text{Matrix form:}\quad & \vec v_\pi = \vec r_\pi + \gamma P_\pi \vec v_\pi \;\Longrightarrow\; \vec v_\pi = (I-\gamma P_\pi)^{-1}\vec r_\pi \end{aligned}\]

The Bellman equation looks different in different sources, but it's the same equation. Write the \(q\) form first, then average over actions to get the \(v\) form.

Building \(P_\pi\) and \(\vec r_\pi\) (grid world)

  1. Lecture conventions. Moving off the grid or into a blocked cell gives reward −1 and leaves you where you are (a "bounce"). Ordinary moves give 0. A special cell can be a trap door, e.g. any action in cell 10 sends you to cell 6 with probability 1, and its +5 is collected on that step.
  2. \(\vec r_\pi\): \(r(s)=\sum_a\pi(a\mid s)\,r(s,a)\). For the random walk (¼ each way) in a corner cell with two walls: \(r=\tfrac14(-1)+\tfrac14(0)+\tfrac14(-1)+\tfrac14(0)=-\tfrac12\). A cell with one wall gets \(-\tfrac14\).
  3. \(P_\pi\) row for \(s\): \(p(s'\mid s)=\sum_a p(s'\mid s,a)\,\pi(a\mid s)\). Bounces add to the diagonal. A corner cell under the random walk has ½ on the diagonal and ¼ on each of its two neighbors. A trap-door row has a single 1.

Finding the optimal policy (the lecture teaches policy iteration)

  1. Start from the random-walk policy (every action equally likely).
  2. Evaluate: \(\vec v_\pi=(I-\gamma P_\pi)^{-1}\vec r_\pi\). For large problems the lecture also shows iterative evaluation: start at \(\vec v=0\) and repeat \(\vec v\leftarrow\vec r_\pi+\gamma P_\pi\vec v\). You can sweep state by state using only old values, or using new values as soon as they're computed.
  3. Improve (greedy): in each state, compute \(q(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v(s')\) and pick the best action. In a grid this "chases" the highest neighboring value. Ties are split with equal probability, so the new policy can be random (e.g. up or right, ½ each).
  4. Repeat until the values, or equivalently the policy, stop changing.

Optimality. \(\pi^*\) is optimal if \(v_{\pi^*}(s)\ge v_\pi(s)\) for every \(s\) and every \(\pi\). It may not be unique, but every optimal policy has the same \(v^*(s)=\max_\pi v_\pi(s)\). Also \(q^*=\max_\pi q_\pi\), \(v^*(s)=\max_a q^*(s,a)\), and \(\pi^*(s)=\arg\max_a q^*(s,a)\).

Value iteration (repeat \(v\leftarrow\max_a[r(s,a)+\gamma\sum p\,v]\)) isn't taught in the lectures. Use policy iteration on the exam.

Traps
  • \(\gamma\) multiplies the next state's value, not the current reward. In the \(q\) form, \(r(s,a)\) sits outside the sum over \(s'\).
  • Ties in the improvement step: split the probability evenly. Code that uses argmax silently picks the first action and can give a different answer.
  • Rounding: −3.708 and −3.679 both display as −3.7. Compare the full values before declaring a tie. The instructor tells you to pause and check the arrows yourself.
  • Staying put is never chosen in the grid unless it's a real action. A bounce is a −1 move, not a free stay.
  • With \(\gamma=1\) and no terminal state, values can diverge.

def stationary(P):
    n = P.shape[0]
    A = np.vstack([P.T - np.eye(n), np.ones(n)])
    b = np.zeros(n + 1); b[-1] = 1
    return np.linalg.lstsq(A, b, rcond=None)[0]

def reach(P):                      # R[i,j] True if i -> j (n >= 0)
    n = len(P); A = ((P > 0) | np.eye(n, dtype=bool)).astype(int)
    return mp(A, n) > 0
R = reach(P); C = R & R.T          # C[i,j]: i and j communicate

from math import gcd
def period(P, i, nmax=50):
    d = 0
    for n in range(1, nmax + 1):
        if mp(P, n)[i, i] > 1e-12: d = gcd(d, n)
    return d

tv = lambda mu, nu: 0.5 * np.abs(np.asarray(mu) - np.asarray(nu)).sum()

Module 4: first-step systems

def hit_time(P, A):                # u_i = 1 + sum_k p_ik u_k, u_A = 0
    idx = [s for s in range(len(P)) if s not in A]
    u = np.zeros(len(P))
    u[idx] = np.linalg.solve(np.eye(len(idx)) - P[np.ix_(idx, idx)], np.ones(len(idx)))
    return u

def return_time(P, j):             # m_j = 1 + sum_k p_jk u_k, with u_j = 0
    return 1 + P[j] @ hit_time(P, [j])

def hit_before(P, A, B):           # p_i = sum_k p_ik p_k, p_A = 1, p_B = 0
    idx = [s for s in range(len(P)) if s not in A + B]
    b = P[np.ix_(idx, A)].sum(axis=1)
    p = np.zeros(len(P)); p[A] = 1
    p[idx] = np.linalg.solve(np.eye(len(idx)) - P[np.ix_(idx, idx)], b)
    return p

def visits(P, t):                  # W[i,j] = expected visits to j before hitting t
    idx = [s for s in range(len(P)) if s != t]
    W = np.linalg.inv(np.eye(len(idx)) - P[np.ix_(idx, idx)])
    return idx, W                  # rows of W sum to hit_time(P,[t])[idx]

Metropolis–Hastings & Gibbs

rng = np.random.default_rng(1)

def metropolis(log_target, x0, n, step=1.0):
    x, out, acc = x0, np.empty(n), 0
    for i in range(n):
        y = x + step * rng.normal()
        if np.log(rng.uniform()) < log_target(y) - log_target(x):
            x, acc = y, acc + 1
        out[i] = x                    # record x even on rejection
    return out, acc / n

def mh_independence(target, q_sample, q_pdf, x0, n):   # lecture style
    x, out = x0, []
    for _ in range(n):
        y = q_sample()
        ratio = (target(y) / q_pdf(y)) / (target(x) / q_pdf(x))
        if rng.uniform() <= ratio:    # no min needed
            x = y
        out.append(x)                 # repeat x on rejection
    return np.array(out)

def gibbs_bvn(rho, n):
    x = y = 0.0; s = np.sqrt(1 - rho**2); out = np.empty((n, 2))
    for i in range(n):
        x = rng.normal(rho * y, s)
        y = rng.normal(rho * x, s)
        out[i] = x, y
    return out

Gelman–Rubin & accept–reject

def gelman_rubin(chains):            # array shape (m, n)
    m, n = chains.shape
    W = chains.var(axis=1, ddof=1).mean()
    B = n * chains.mean(axis=1).var(ddof=1)
    V = (n - 1) / n * W + B / n
    return np.sqrt(V / W)

# lecture letters: h = proposal pdf, g = c*h = envelope (g >= f)
def accept_reject(f, h_sample, h_pdf, c, n):
    out, tries = [], 0
    while len(out) < n:
        y = h_sample(); tries += 1
        if rng.uniform() <= f(y) / (c * h_pdf(y)):    # = f(Y)/g(Y)
            out.append(y)
    return np.array(out), n / tries       # acceptance rate ~ 1/c

def inv_exp(lam, n):                      # lecture's F^-1(u) = -ln(1-u)/lam
    return -np.log(1 - rng.uniform(size=n)) / lam

Policy evaluation & policy iteration

# P[a]: (S,S) matrix p(s'|s,a);  r[a]: (S,) reward r(s,a)
# pi: (S,A) matrix of probabilities pi(a|s)
def evaluate(P, r, pi, gamma):
    P_pi = sum(pi[:, [a]] * P[a] for a in range(len(P)))   # p(s'|s)
    r_pi = sum(pi[:, a] * r[a] for a in range(len(P)))     # r(s)
    return np.linalg.solve(np.eye(len(r_pi)) - gamma * P_pi, r_pi)

def policy_iteration(P, r, gamma, tol=1e-9):
    A, S = len(P), len(r[0])
    pi = np.full((S, A), 1 / A)                  # start: random walk
    while True:
        v = evaluate(P, r, pi, gamma)
        q = np.array([r[a] + gamma * P[a] @ v for a in range(A)]).T  # (S,A)
        best = q >= q.max(axis=1, keepdims=True) - tol
        new = best / best.sum(axis=1, keepdims=True)    # split ties evenly
        if np.allclose(new, pi):
            return pi, v
        pi = new
