# CU Boulder — Coursework

Personal coursework, labs, study notes, and exam prep for University of
Colorado Boulder (Coursera) courses. Each course lives in its own top-level
directory.

|--------|--------|-------------|

### Introduction to Machine Learning: Supervised Learning

Organized by part and module. Each module contains a hands-on `Lab` (Python
exercises solved against an autograder) and a `Quiz` with the module's graded
questions. `Textbooks` lists the recommended readings (ISLP and ESL).

Labs are standalone Python scripts (`Problem*.py`, with a shared `Setup.py`).
Solution code is bracketed by `#####personal code#####` markers; each script
prints the value expected by the course autograder.

> Note for Windows users: this folder name contains a `:`, which Windows
> can't create. Clone with `git -c core.protectNTFS=false` and a sparse
> checkout, or browse it on GitHub.

## Not included

Textbooks, assigned readings, lecture transcripts, and course slides stay
local only (see `.gitignore`). They belong to their authors and the course.
