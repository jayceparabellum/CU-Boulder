Module 2

Point Estimation

Continuous distributions (not on the allowed table)

  • Uniform(a, b). \(f(x)=\frac{1}{b-a}I_{(a,b)}(x)\), mean \(\frac{a+b}2\), variance \(\frac{(b-a)^2}{12}\).
  • Exponential(rate λ). \(f(x)=\lambda e^{-\lambda x}I_{(0,\infty)}(x)\), mean \(1/\lambda\), variance \(1/\lambda^2\), \(P(X\gt x)=e^{-\lambda x}\).
  • Gamma(α, β), β a rate. \(f(x)=\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}\), mean \(\alpha/\beta\), variance \(\alpha/\beta^2\). Exponential(λ) = Γ(1, λ).
  • Normal(μ, σ²). \(f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-(x-\mu)^2/(2\sigma^2)}\). \(Z=(X-\mu)/\sigma\sim N(0,1)\).
  • χ²(n) = Γ(n/2, 1/2): mean \(n\), variance \(2n\). Beta(α, β): mean \(\frac{\alpha}{\alpha+\beta}\).

Know cold

  • Linearity. \(E[aX+b]=aE[X]+b\), \(\mathrm{Var}[aX+b]=a^2\mathrm{Var}[X]\), \(\mathrm{Var}[X]=E[X^2]-(E[X])^2\).
  • Sums. \(\mathrm{Var}[X\pm Y]=\mathrm{Var}[X]+\mathrm{Var}[Y]\pm2\,\mathrm{Cov}(X,Y)\), and the covariance is 0 when independent. So \(E[\bar X]=\mu\), \(\mathrm{Var}[\bar X]=\sigma^2/n\).
  • Sums of iid variables. Bernoulli(p) → bin(n, p). Poisson(λ) → Poisson(nλ). Exp(λ) → Γ(n, λ). Γ(αᵢ, β) → Γ(Σαᵢ, β). Normals → normal.
  • Transformations. CDF method: \(F_Y(y)=P(g(X)\le y)\), then differentiate. Scaling: if \(X\sim\Gamma(\alpha,\beta)\) then \(cX\sim\Gamma(\alpha,\beta/c)\).
  • Unbiased. \(E[\hat\theta]=\theta\). \(S^2=\frac{1}{n-1}\sum(X_i-\bar X)^2\) is unbiased for σ²; dividing by \(n\) gives \(E=\frac{n-1}{n}\sigma^2\).
  • \(E[g(X)]\ne g(E[X])\) in general. \(\bar X^2\) is biased for \(\mu^2\), since \(E[\bar X^2]=\mu^2+\sigma^2/n\).

Probability tools from the lectures

  • Change of variables (g invertible): \(f_Y(y)=f_X\!\big(g^{-1}(y)\big)\left|\frac{d}{dy}g^{-1}(y)\right|\). If g isn't invertible (e.g. \(X^2\)), go through the CDF instead.
  • LOTUS. \(E[g(X)]=\int g(x)f_X(x)\,dx\); no need to find the distribution of \(g(X)\) first. Works for joint pdfs too.
  • Independence. X, Y are independent iff the joint pdf factors into an x-part and a y-part including the indicators. Quick check: the support is a rectangle. Independent ⇒ \(E[g(X)h(Y)]=E[g(X)]E[h(Y)]\), but not conversely.
  • Covariance & correlation. \(\mathrm{Cov}(X,Y)=E[XY]-\mu_X\mu_Y\), \(\rho=\frac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1]\). Independent ⇒ uncorrelated, not conversely (e.g. \(X\in\{-1,0,1\}\), \(Y=X^2\)).
  • Gamma function. \(\Gamma(\alpha)=\int_0^\infty x^{\alpha-1}e^{-x}dx\), \(\Gamma(1)=1\), \(\Gamma(\alpha)=(\alpha-1)\Gamma(\alpha-1)\), \(\Gamma(n)=(n-1)!\).
  • "Integrate without integrating." If an integrand looks like a known pdf without its constant, put the constant in and compensate outside; the pdf part integrates to 1. This is how \(E[1/Y]\) and MGFs for gamma variables are done in lecture.
  • Expected value of an indicator is a probability: \(E[I_A(X)]=P(X\in A)\). So a sample proportion is unbiased for the probability it counts.

Moment generating functions

  • \(M_X(t)=E[e^{tX}]\). It must exist on a neighborhood of 0, and it uniquely determines the distribution: match an MGF, name the distribution.
  • For iid \(X_i\): \(M_{\sum X_i}(t)=[M_X(t)]^n\). For independent, non-identical \(X_i\): \(M_{\sum X_i}(t)=\prod M_{X_i}(t)\).
\[ \begin{aligned} \text{Bernoulli}(p):&\ 1-p+pe^t &\quad \text{bin}(n,p):&\ (1-p+pe^t)^n &\quad \text{Poisson}(\lambda):&\ e^{\lambda(e^t-1)}\\ \text{Exp}(\lambda):&\ \tfrac{\lambda}{\lambda-t},\ t\lt\lambda &\quad \Gamma(\alpha,\beta):&\ \left(\tfrac{\beta}{\beta-t}\right)^{\alpha},\ t\lt\beta &\quad \chi^2(n):&\ (1-2t)^{-n/2} \end{aligned}\]
  • More sums: m iid bin(n, p) → bin(nm, p). Independent \(\chi^2(n_i)\) → \(\chi^2(\sum n_i)\). Independent \(N(\mu_i,\sigma_i^2)\): \(\sum a_iX_i\sim N(\sum a_i\mu_i,\ \sum a_i^2\sigma_i^2)\).
  • \(Z^2\sim\chi^2(1)\). If \(X\sim\Gamma(n,\beta)\) then \(2\beta X\sim\chi^2(2n)\), the key move for exponential confidence intervals.

Method of moments

  1. Write the population moments as functions of the parameters: \(E[X]=\mu_1(\theta)\), \(E[X^2]=\mu_2(\theta)\), … (as many as there are parameters).
  2. Set each equal to its sample moment: \(\mu_k(\theta)=\frac1n\sum X_i^k\).
  3. Solve for the parameters. Using \(\frac1n\sum X_i^2-\bar X^2=\frac1n\sum(X_i-\bar X)^2\) usually simplifies the algebra.
Traps
  • Gamma and exponential use a rate β in this course (mean α/β). R's qgamma(p, shape, rate) matches only if you pass the rate.
  • MoM estimators can land outside the parameter space, and they're often biased. Check both before you trust one.
  • Unbiasedness doesn't survive nonlinear maps: \(1/\bar X\) is biased for λ even though \(\bar X\) is unbiased for \(1/\lambda\).
  • Two geometrics: \(\text{geom}_1(p)\) counts trials to the first success (\(x=1,2,\dots\)); \(\text{geom}_0(p)\) counts failures before it (\(x=0,1,\dots\)). Check which one the problem means before using the table.
  • "Sample variance" means \(S^2\) with \(n-1\) unless a question says otherwise.
  • The "Shape of Data" lab asks you to tell exponential, normal and Pareto data apart from a histogram. Pareto isn't in this guide's tables. Look up the course's form of its pdf in your distribution notes so you can recognize it (very heavy right tail, support starting at a positive minimum).

P2.3
\(X_1,\dots,X_n\) iid Exp(λ). Find an unbiased estimator of λ built from \(\bar X\).
Show solution

\(\sum X_i\sim\Gamma(n,\lambda)\), and for \(Y\sim\Gamma(n,\lambda)\), \(E[1/Y]=\frac{\lambda}{n-1}\). So \(E[1/\bar X]=nE[1/Y]=\frac{n\lambda}{n-1}\). Multiply by \(\frac{n-1}{n}\).

λ̂ = (n−1) / (n X̄) = (n−1)/ΣXᵢ

P2.4
\(X_1,\dots,X_n\) iid Poisson(λ). Use MGFs to find the distribution of \(Y=\sum X_i\).

\(M_Y(t)=[M_X(t)]^n=\big(e^{\lambda(e^t-1)}\big)^n=e^{n\lambda(e^t-1)}\), the Poisson MGF with parameter \(n\lambda\). MGFs determine the distribution.

Y ~ Poisson(nλ)

Module 3

Maximum Likelihood Estimation

Finding an MLE

  1. Likelihood: \(L(\theta)=\prod_{i=1}^n f(x_i;\theta)\), with every indicator kept.
  2. Log it: \(\ell(\theta)=\ln L(\theta)\). Products become sums.
  3. Solve \(\frac{\partial\ell}{\partial\theta}=0\) (one equation per parameter), and check it's a maximum.
  4. If θ appears in an indicator (the support depends on θ), don't differentiate. Sketch \(L(\theta)\) and find the max directly. It's usually at an order statistic.

A likelihood is anything proportional to the joint pdf, so drop multiplicative factors without θ (indicators without θ, \(\prod x_i!\), \(2\pi\)…). With two parameters, set both partials to 0 and solve the system together; for the normal, differentiate with respect to σ² as a single symbol.

Know cold

  • Standard MLEs. Bernoulli: \(\hat p=\bar X\). Poisson: \(\hat\lambda=\bar X\). Exp(λ): \(\hat\lambda=1/\bar X\). Normal: \(\hat\mu=\bar X\), \(\hat\sigma^2=\frac1n\sum(X_i-\bar X)^2\) (biased). Unif(0, θ): \(\hat\theta=X_{(n)}=\max X_i\).
  • Invariance. If \(\hat\theta\) is the MLE of θ, then \(\tau(\hat\theta)\) is the MLE of \(\tau(\theta)\). E.g. the MLE of σ is \(\sqrt{\hat\sigma^2}\), and the MLE of \(P(X\gt1)=e^{-\lambda}\) is \(e^{-1/\bar X}\).
  • Bias. \(B(\hat\theta)=E[\hat\theta]-\theta\).
  • MSE. \(\mathrm{MSE}(\hat\theta)=E[(\hat\theta-\theta)^2]=\mathrm{Var}[\hat\theta]+B(\hat\theta)^2\). If any competitor is biased, compare by MSE.
  • Relative efficiency (both unbiased): \(\mathrm{eff}(\hat\theta_1,\hat\theta_2)=\dfrac{\mathrm{Var}[\hat\theta_2]}{\mathrm{Var}[\hat\theta_1]}\). Greater than 1 means \(\hat\theta_1\) is more efficient.
  • Max of n iid Unif(0, θ). \(F_{X_{(n)}}(x)=(x/\theta)^n\), \(E[X_{(n)}]=\frac{n}{n+1}\theta\), \(\mathrm{Var}[X_{(n)}]=\frac{n\theta^2}{(n+1)^2(n+2)}\).
  • Min of n iid Exp(λ) is Exp(nλ).
Traps
  • Invariance gives the MLE of τ(θ). It doesn't make that MLE unbiased.
  • With an indicator like \(I_{(0,\theta)}(\max x_i)\), setting the derivative to 0 gives nonsense (\(-n/\theta=0\)). Look at where L is nonzero.
  • For two-parameter normal, \(\hat\sigma^2\) divides by \(n\), not \(n-1\). Don't swap in \(S^2\) when a question asks for the MLE.
P3.1
\(X_1,\dots,X_n\) iid Exp(λ). Find the MLE of λ and of \(P(X_1\gt 2)\).
Show solution

\(\ell(\lambda)=n\ln\lambda-\lambda\sum x_i\), \(\ell'=n/\lambda-\sum x_i=0\). \(P(X\gt2)=e^{-2\lambda}\), then apply invariance.

λ̂ = 1/X̄; MLE of P(X > 2) = e^(−2/X̄)

P3.2
\(X_1,\dots,X_n\) iid Unif(0, θ). Find the MLE, its bias, and an unbiased multiple of it.
Show solution

\(L(\theta)=\theta^{-n}I_{[X_{(n)},\infty)}(\theta)\). That's decreasing in θ wherever it's nonzero, so it's maximized at the smallest allowed θ. \(E[X_{(n)}]=\frac{n}{n+1}\theta\), bias \(-\frac{\theta}{n+1}\).

θ̂ = X₍ₙ₎ (max); unbiased version (n+1)/n · X₍ₙ₎

P3.3
Compare the two unbiased estimators of θ for Unif(0, θ): \(2\bar X\) (P2.1) and \(\frac{n+1}{n}X_{(n)}\). Which is more efficient?
Show solution

\(\mathrm{Var}[2\bar X]=\frac{\theta^2}{3n}\). \(\mathrm{Var}[\frac{n+1}{n}X_{(n)}]=\frac{(n+1)^2}{n^2}\cdot\frac{n\theta^2}{(n+1)^2(n+2)}=\frac{\theta^2}{n(n+2)}\). Ratio: \(\frac{\theta^2/(3n)}{\theta^2/(n(n+2))}\).

eff = (n+2)/3 > 1 for n ≥ 2, so the max-based estimator wins

P3.4
(Lecture example) \(X_1,\dots,X_n\) iid Poisson(λ). Estimate \(p=P(X\gt0)=1-e^{-\lambda}\) two ways: the sample proportion \(\hat p_1=\frac1n\sum I(X_i\gt0)\), and the MLE \(\hat p_2\). Which is unbiased?
Show solution

\(E[\hat p_1]=E[I(X_1\gt0)]=P(X_1\gt0)=p\), so it's unbiased. The MLE of λ is \(\bar X\); by invariance \(\hat p_2=1-e^{-\bar X}\). With \(Y=\sum X_i\sim\) Poisson(nλ), \(E[e^{-\bar X}]=M_Y(-1/n)=e^{n\lambda(e^{-1/n}-1)}\). For n = 5, λ = 1 that gives \(E[\hat p_2]=0.596\) against p = 0.632.

p̂₁ is unbiased. p̂₂ = 1 − e^(−X̄) is biased but asymptotically unbiased: E[p̂₂] = 1 − exp(nλ(e^(−1/n) − 1)) → p.

(Graded lab) Poisson(5) data. \(\hat\lambda_1=\bar X\) from n = 12 observations, \(\hat\lambda_2=\bar X\) from n = 8. Find the bias, variance and MSE of \(\hat\lambda_1\), and the efficiency of \(\hat\lambda_1\) relative to \(\hat\lambda_2\).

\(\bar X\) is unbiased with variance λ/n, so MSE = Var = 5/12. eff \(=\frac{\mathrm{Var}[\hat\lambda_2]}{\mathrm{Var}[\hat\lambda_1]}=\frac{5/8}{5/12}\). These are theoretical values; they don't use the observed data.

When the MLE has no closed form (graded lab, Module 4)

Gamma(α, β) with both unknown: \(\partial\ell/\partial\beta=0\) gives \(\hat\beta=\hat\alpha/\bar x\), but the α equation has no algebraic solution. Substitute \(\beta=\alpha/\bar x\) into \(\ell\) (the profile log-likelihood), then maximize over α numerically: plot it on a grid and take alpha[which.max(ell)], or use optimize(f, lower, upper, maximum = TRUE).

\[ \ell(\alpha,\alpha/\bar x) = -n\ln\Gamma(\alpha) + n\alpha\ln(\alpha/\bar x) + (\alpha-1)\textstyle\sum\ln x_i - n\alpha \]
Module 4

Large Sample Properties of MLEs

Fisher information & the Cramér–Rao lower bound

\[ I_n(\theta) = E\!\left[\left(\frac{\partial}{\partial\theta}\ln f(\mathbf X;\theta)\right)^{\!2}\right] = -E\!\left[\frac{\partial^2}{\partial\theta^2}\ln f(\mathbf X;\theta)\right] = n\,I_1(\theta) \]
\[ \text{For any unbiased } \hat\tau \text{ of } \tau(\theta):\qquad \mathrm{Var}[\hat\tau] \;\ge\; \frac{[\tau'(\theta)]^2}{I_n(\theta)} \]

An unbiased estimator that hits the bound is a UMVUE (uniformly minimum-variance unbiased estimator). The second-derivative form of \(I_n\) is almost always faster.

Know cold

  • Bernoulli(p). \(I_1=\frac{1}{p(1-p)}\), CRLB \(\frac{p(1-p)}{n}\), and \(\bar X\) attains it.
  • Poisson(λ). \(I_1=1/\lambda\), CRLB \(\lambda/n\), and \(\bar X\) attains it.
  • Exp(λ). \(I_1=1/\lambda^2\). CRLB for λ is \(\lambda^2/n\). For the mean \(\tau=1/\lambda\) it's \(\frac{1}{n\lambda^2}\), which \(\bar X\) attains.
  • N(μ, σ²), σ² known. \(I_1=1/\sigma^2\), CRLB \(\sigma^2/n\).
  • Consistent: \(\hat\theta_n\xrightarrow{P}\theta\). Sufficient condition: (asymptotically) unbiased and \(\mathrm{Var}[\hat\theta_n]\to0\).
  • Asymptotic properties of the MLE (under regularity conditions): consistent, asymptotically unbiased, asymptotically efficient, and
\[ \hat\theta_n \;\overset{\text{approx}}{\sim}\; N\!\left(\theta,\; \frac{1}{I_n(\theta)}\right) \quad\Longrightarrow\quad \hat\theta_n \pm z_{\alpha/2}\sqrt{1/I_n(\hat\theta_n)} \text{ is an approximate CI} \]

Sampling distributions from normal data

  • Any linear combination of independent normals is normal.
  • \(Z^2\sim\chi^2(1)\), and sums of independent χ² add their degrees of freedom.
  • \(\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)\), independent of \(\bar X\).
  • \(T=\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)\), and \(F=\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F(n_1-1,\,n_2-1)\).
  • Moments: \(\chi^2(n)\) has mean n, variance 2n. \(t(n)\) has mean 0, variance \(\frac{n}{n-2}\) (n > 2). \(F(n_1,n_2)\) has mean \(\frac{n_2}{n_2-2}\).

Inequalities, convergence and the CLT (lecture material)

  • Markov (general form). For \(g\ge0\): \(P(g(X)\ge c)\le\frac{E[g(X)]}{c}\).
  • Chebyshev. \(P(|X-\mu|\ge k\sigma)\le\frac1{k^2}\), or equivalently \(P(|X-\mu|\ge\varepsilon)\le\frac{\sigma^2}{\varepsilon^2}\).
  • Convergence in probability. \(\hat\theta_n\xrightarrow{P}\theta\) if \(P(|\hat\theta_n-\theta|\gt\varepsilon)\to0\) for every ε > 0. Use Chebyshev on \(\bar X\) to get the WLLN: \(\bar X_n\xrightarrow{P}\mu\).
  • Algebra of limits. If \(X_n\xrightarrow{P}a\) and \(Y_n\xrightarrow{P}b\), then sums, products, quotients (b ≠ 0) and continuous g carry over: \(g(X_n)\xrightarrow{P}g(a)\). That's why \(1/\bar X\) is consistent for λ in the exponential.
  • Convergence in distribution (CDFs converge) is weaker than convergence in probability.
  • CLT. For iid data with mean μ and finite σ²: \(\frac{\bar X_n-\mu}{\sigma/\sqrt n}\xrightarrow{d}N(0,1)\), so \(\bar X\overset{\text{approx}}{\sim}N(\mu,\sigma^2/n)\) for large n, whatever the distribution.
  • Score. \(E\!\left[\frac{\partial}{\partial\theta}\ln f(X;\theta)\right]=0\), so \(I_1\) is the variance of the score.
  • Asymptotically efficient means \(\frac{\text{CRLB}}{\mathrm{Var}[\hat\theta_n]}\to1\).
Traps
  • The CRLB needs regularity: the support can't depend on θ. For Unif(0, θ) it doesn't apply, which is why \(\frac{n+1}{n}X_{(n)}\) can beat "the bound."
  • Don't forget the \([\tau'(\theta)]^2\) numerator when the target is a function of θ.
  • \(I_n=nI_1\) only for iid samples. Compute \(I_1\) from one observation, then multiply.
  • Asymptotic normality of the MLE also needs regularity. The graded lab simulated \(X_{(n)}\) for Unif(5, θ): its histogram is piled against θ and skewed left, not normal, even with n = 1000.
P4.1
\(X_1,\dots,X_n\) iid Poisson(λ). Find \(I_n(\lambda)\), the CRLB for unbiased estimators of λ, and whether \(\bar X\) attains it.
Show solution

\(\ln f=x\ln\lambda-\lambda-\ln x!\). \(\frac{\partial^2}{\partial\lambda^2}\ln f=-x/\lambda^2\), so \(I_1=E[X]/\lambda^2=1/\lambda\). \(\mathrm{Var}[\bar X]=\lambda/n\).

I_n = n/λ, CRLB = λ/n, attained, so X̄ is the UMVUE

P4.2
\(X_1,\dots,X_n\) iid Exp(λ). Find the CRLB for unbiased estimators of \(\tau(\lambda)=1/\lambda\), and use asymptotic normality to write an approximate 95% CI for λ.
Show solution

\(\ln f=\ln\lambda-\lambda x\), second derivative \(-1/\lambda^2\), so \(I_n=n/\lambda^2\). \(\tau'=-1/\lambda^2\), so the CRLB is \(\frac{1/\lambda^4}{n/\lambda^2}\). For the CI: \(\hat\lambda=1/\bar X\) with approximate variance \(1/I_n(\hat\lambda)=\hat\lambda^2/n\).

CRLB = 1/(nλ²) (attained by X̄). Approx CI: λ̂ ± 1.96·λ̂/√n with λ̂ = 1/X̄

P4.3
Is \(X_{(n)}\) a consistent estimator of θ for Unif(0, θ)?
Show solution

\(E[X_{(n)}]=\frac{n}{n+1}\theta\to\theta\) (asymptotically unbiased), and \(\mathrm{Var}=\frac{n\theta^2}{(n+1)^2(n+2)}\to0\).

Yes

P4.4
(Lecture example) \(X_1,\dots,X_{100}\) iid Γ(3, 2) (rate 2). Approximate \(P(\bar X\gt1.4)\).

\(\mu=3/2=1.5\), \(\sigma^2=3/4\), so \(\mathrm{Var}[\bar X]=3/400\) and SD \(=0.0866\). By the CLT, \(z=\frac{1.4-1.5}{0.0866}=-1.1547\). In R: 1 - pnorm(1.4, 1.5, sqrt(3/400)).

≈ 0.876 (the lecture rounds z to −1.15 and gets 0.8749)

P4.5
X has mean 50 and standard deviation 5, distribution unknown. Give a lower bound for \(P(40\lt X\lt60)\).
Show solution

The interval is μ ± 2σ, so Chebyshev with k = 2 gives \(P(|X-50|\ge10)\le1/4\).

Module 5

Confidence Intervals Involving the Normal Distribution

Notation and interpretation

  • Critical values are upper-tail. \(z_\alpha\) cuts off area α to the right: \(z_{0.05}=1.645\), \(z_{0.025}=1.96\), \(z_{0.005}=2.576\). Same for \(t_{\alpha,\nu}\), \(\chi^2_{\alpha,\nu}\), \(F_{\alpha,\nu_1,\nu_2}\). In R, \(z_\alpha\) = qnorm(1 - alpha).
  • Interpretation. The interval is random, not μ. If you repeated the sampling many times, about 100(1−α)% of the intervals would capture μ. Never say "μ is in (a, b) with probability 0.95."
  • "Large" means n > 30 (the course's rule of thumb).
  • Computing \(S^2\) by hand: \(S^2=\frac{\sum x_i^2-n\bar x^2}{n-1}\).
  • Why symmetric critical values? For a symmetric pivot (Z, t), splitting α equally gives the shortest interval. Pick the confidence level before you look at the data.

One sample: CI for μ

\[ \begin{aligned} \text{Normal, } \sigma^2 \text{ known:}&\quad \bar X \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt n}\\ \text{Any distribution, } n\gt30,\ \sigma^2 \text{ unknown:}&\quad \bar X \pm z_{\alpha/2}\,\frac{S}{\sqrt n}\ \ (\text{approximate, by CLT})\\ \text{Normal, small } n,\ \sigma^2 \text{ unknown:}&\quad \bar X \pm t_{\alpha/2,\,n-1}\,\frac{S}{\sqrt n} \end{aligned}\]

Two independent samples: CI for μ₁ − μ₂

\[ \begin{aligned} \sigma_1^2,\sigma_2^2 \text{ known:}&\quad (\bar X_1-\bar X_2) \pm z_{\alpha/2}\sqrt{\tfrac{\sigma_1^2}{n_1}+\tfrac{\sigma_2^2}{n_2}}\\ \text{both large, unknown:}&\quad (\bar X_1-\bar X_2) \pm z_{\alpha/2}\sqrt{\tfrac{S_1^2}{n_1}+\tfrac{S_2^2}{n_2}}\\ \text{normal, } \sigma_1^2=\sigma_2^2 \text{ unknown:}&\quad (\bar X_1-\bar X_2) \pm t_{\alpha/2,\,n_1+n_2-2}\; S_p\sqrt{\tfrac1{n_1}+\tfrac1{n_2}},\quad S_p^2=\tfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}\\ \text{normal, unequal, small (Welch):}&\quad (\bar X_1-\bar X_2) \pm t_{\alpha/2,\,\nu}\sqrt{\tfrac{S_1^2}{n_1}+\tfrac{S_2^2}{n_2}},\quad \nu=\frac{\left(\frac{S_1^2}{n_1}+\frac{S_2^2}{n_2}\right)^2}{\frac{(S_1^2/n_1)^2}{n_1-1}+\frac{(S_2^2/n_2)^2}{n_2-1}} \end{aligned}\]

If a CI for μ₁ − μ₂ contains 0, the data don't show a difference at that confidence level. If it's entirely positive (or negative), they suggest μ₁ > μ₂ (or <).

Traps
  • qt(0.975, df) for a 95% interval, not qt(0.95, df). Split α across both tails.
  • "Variance is 15.3" means σ² = 15.3; divide that by n, not its square.
  • Pooled t needs the equal-variance assumption stated in the problem. Without it, use Welch (round ν down if a table is involved; R accepts fractional df).
  • The t interval needs normal data. For small n from an unknown non-normal distribution, none of these intervals is justified. The labs check normality with a Q–Q plot (qqnorm(x); qqline(x)): points close to a straight line support normality.
  • Interpretation true/false (graded lab). "90% chance μ is in [a, b]": false. "90% chance the next observation is in [a, b]": false (a CI is for μ, not for a new value). "A 95% CI from the same data is wider": true. Under repeated sampling, about (1−α) of intervals cover μ, so 10 intervals at 60% should hit about 6.
  • Do what the question says. One graded lab asked for qnorm with the sample SD for n = 20; if a problem names the method, use it even if you'd pick t.

Module 6

Beyond Normality: Confidence Intervals Unleashed!

The 4-step pivot method (works for everything)

  1. Choose a statistic whose distribution you know and that depends on the unknown parameter (\(\bar X\), \(\sum X_i\), \(S^2\), \(X_{(1)}\), …).
  2. Build a pivot: a function of the statistic and the parameter whose distribution is known and parameter-free (N(0,1), t, χ², F, Exp(1), Γ(n, n)…).
  3. Find critical values that cut off α/2 in each tail of the pivot's distribution.
  4. Put the pivot between them and solve for the parameter "in the middle." Watch for inequality flips when you take reciprocals.

Proportions

\[ \hat p \pm z_{\alpha/2}\sqrt{\frac{\hat p(1-\hat p)}{n}},\qquad (\hat p_1-\hat p_2) \pm z_{\alpha/2}\sqrt{\frac{\hat p_1(1-\hat p_1)}{n_1}+\frac{\hat p_2(1-\hat p_2)}{n_2}} \]

Is n large enough? Use normality only if \(\hat p\pm3\sqrt{\hat p(1-\hat p)/n}\) lies entirely inside [0, 1]. Check each sample separately for the two-sample case.

Variances (normal data)

\[ \sigma^2:\ \left(\frac{(n-1)S^2}{\chi^2_{\alpha/2,\,n-1}},\ \frac{(n-1)S^2}{\chi^2_{1-\alpha/2,\,n-1}}\right) \qquad\qquad \frac{\sigma_1^2}{\sigma_2^2}:\ \left(\frac{S_1^2/S_2^2}{F_{\alpha/2,\,n_1-1,\,n_2-1}},\ \frac{S_1^2/S_2^2}{F_{1-\alpha/2,\,n_1-1,\,n_2-1}}\right) \]

With upper-tail notation, the larger critical value goes in the denominator of the lower endpoint. For σ, take square roots of both endpoints. \(F_{1-\alpha/2,\nu_1,\nu_2}=1/F_{\alpha/2,\nu_2,\nu_1}\).

One-sided intervals (covered in lecture): put all of α in one tail. Upper bound for σ²: \(\left(0,\ \frac{(n-1)S^2}{\chi^2_{1-\alpha,\,n-1}}\right)\); lower bound: \(\left(\frac{(n-1)S^2}{\chi^2_{\alpha,\,n-1}},\ \infty\right)\).

Non-normal pivots from the lectures (Exp(λ))

  • From the sum. \(\sum X_i\sim\Gamma(n,\lambda)\) ⇒ \(\lambda\bar X\sim\Gamma(n,n)\) and \(2\lambda\sum X_i = 2n\lambda\bar X\sim\chi^2(2n)\).
    \[ \chi^2_{1-\alpha/2,\,2n} \lt 2n\lambda\bar X \lt \chi^2_{\alpha/2,\,2n} \;\Longrightarrow\; \left(\frac{\chi^2_{1-\alpha/2,\,2n}}{2\sum X_i},\ \frac{\chi^2_{\alpha/2,\,2n}}{2\sum X_i}\right) \]
  • From the minimum. \(X_{(1)}\sim\text{Exp}(n\lambda)\) ⇒ \(n\lambda X_{(1)}\sim\text{Exp}(1)\). Exp(1) quantiles: \(a=-\ln(1-\alpha/2)\), \(b=-\ln(\alpha/2)\). CI: \(\left(\frac{a}{nX_{(1)}},\ \frac{b}{nX_{(1)}}\right)\). The lecture builds this one one-sided: \(P(n\lambda X_{(1)}\le-\ln\alpha)=1-\alpha\) gives \(\left(0,\ \frac{-\ln\alpha}{nX_{(1)}}\right)\).
Traps
  • χ² and F intervals aren't symmetric around the estimate. Don't write "estimate ± margin."
  • In the course's upper-tail notation, \(\chi^2_{0.025,\nu}\) is the big one, which is qchisq(0.975, nu) in R. Mixing these up swaps your endpoints.
  • The notation isn't consistent across materials. The "Non-Normal CIs in R" lab writes \(\frac{\chi^2_{0.025,2n}}{2n\bar X}\le\lambda\le\frac{\chi^2_{0.975,2n}}{2n\bar X}\) with lower-tail subscripts (qchisq(0.025, 2n) on the left). Don't trust a subscript; sanity-check that the smaller quantile gives the lower endpoint.
  • Proportion CIs use \(\hat p\) inside the square root, but the validity check is ±3 SE, not ±z SE.
  • The minimum-based CI for λ is valid but much wider than the sum-based one. If asked which is better, the sum-based one uses all the data.

Mean CIs

ci_z <- function(xbar, sd, n, conf = .95) xbar + c(-1, 1) * qnorm(1 - (1 - conf)/2) * sd / sqrt(n)
ci_t <- function(xbar, s,  n, conf = .95) xbar + c(-1, 1) * qt(1 - (1 - conf)/2, n - 1) * s / sqrt(n)

ci_pooled <- function(x1, s1, n1, x2, s2, n2, conf = .95) {
  sp <- sqrt(((n1 - 1) * s1^2 + (n2 - 1) * s2^2) / (n1 + n2 - 2))
  (x1 - x2) + c(-1, 1) * qt(1 - (1 - conf)/2, n1 + n2 - 2) * sp * sqrt(1/n1 + 1/n2)
}

ci_welch <- function(x1, s1, n1, x2, s2, n2, conf = .95) {
  v1 <- s1^2 / n1; v2 <- s2^2 / n2
  nu <- (v1 + v2)^2 / (v1^2 / (n1 - 1) + v2^2 / (n2 - 1))
  (x1 - x2) + c(-1, 1) * qt(1 - (1 - conf)/2, nu) * sqrt(v1 + v2)
}

Proportion, variance and exponential CIs

ci_prop <- function(x, n, conf = .95) {
  p <- x / n; se <- sqrt(p * (1 - p) / n)
  print(p + c(-3, 3) * se)                     # must sit inside [0, 1]
  p + c(-1, 1) * qnorm(1 - (1 - conf)/2) * se
}

ci_var <- function(s2, n, conf = .95) {        # sqrt() the result for sigma
  a <- 1 - conf
  (n - 1) * s2 / qchisq(c(1 - a/2, a/2), n - 1)
}

ci_ratio <- function(s1sq, n1, s2sq, n2, conf = .95) {
  a <- 1 - conf
  (s1sq / s2sq) / qf(c(1 - a/2, a/2), n1 - 1, n2 - 1)
}

ci_exp_sum <- function(sumx, n, conf = .95) {
  a <- 1 - conf
  qchisq(c(a/2, 1 - a/2), 2 * n) / (2 * sumx)
}

ci_exp_min <- function(xmin, n, conf = .95) {
  a <- 1 - conf
  qexp(c(a/2, 1 - a/2)) / (n * xmin)
}
ci_exp_min_upper <- function(xmin, n, conf = .95) c(0, -log(1 - conf) / (n * xmin))
